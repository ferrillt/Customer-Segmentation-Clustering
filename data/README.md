# Data

This project uses the Online Retail dataset from the UCI Machine Learning Repository.

**Dataset source:** Chen, D. (2015). *Online retail* [Data set]. UCI Machine Learning Repository. https://doi.org/10.24432/C5BW33

## Download Instructions

1. Download the Online Retail dataset from the source above.
2. Save the original ZIP archive in this `data/` directory.
3. Ensure the archive is named `online+retail.zip`.
4. Run the Jupyter notebook from the `notebook/` directory.

The notebook reads `Online Retail.xlsx` directly from the ZIP archive. Manual extraction is not required.

## Data Availability

The original dataset is not included in the GitHub repository. It must be downloaded separately to reproduce the analysis.

The notebook preserves the original source data and creates separate DataFrames for cleaning and feature engineering.
